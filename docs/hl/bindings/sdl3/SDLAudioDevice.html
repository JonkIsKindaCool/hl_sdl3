API Documentation

class SDLAudioDevice

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLAudio

A logical audio device opened with SDL_OpenAudioDevice.

Static methods

staticopen(devid:Int, ?spec:SDLAudioSpec):Null<SDLAudioDevice>

Opens an audio device.

Parameters:

devid

DEFAULT_PLAYBACK, DEFAULT_RECORDING, or a specific device ID.

spec

Optional desired audio specification. May be null.

Returns:

A new device, or null on failure.

Variables

gain:Float

Gets or sets the device gain (volume).

read onlyid:Int

The underlying SDL device ID.

Methods

bind(stream:SDLAudioStream):Bool

Binds a stream to this device.

close():Void

Closes the device. May block briefly to finish playing the last buffer.

getChannelMap():Null<Array<Int>>

Returns the device's channel map, or null if unavailable.

isPaused():Bool

Returns true if the device is paused.

pause():Bool

Pauses the device.

resume():Bool

Resumes the device.
