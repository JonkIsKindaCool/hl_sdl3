class SDLTrayEntry

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLTray

@:directlyUsed

Represents an individual item, button, checkbox, or separator within a system tray menu.

Corresponds to SDL_TrayEntry in SDL3.

Methods
