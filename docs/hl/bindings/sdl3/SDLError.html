API Documentation

class SDLError

package hl.bindings.sdl3

Thread-local error message API, mirroring SDL's SDL_GetError / SDL_SetError family. Each thread has its own error message that is set by SDL functions on failure.

Static methods

staticcheck(ok:Bool, ?context:String):Bool

Throws a Haxe exception built from context and the current SDL error message if ok is false. Returns ok unchanged otherwise.

Parameters:

ok

The success flag to check.

context

Optional context string to prepend to the error message.

Returns:

The same ok value passed in.

Throws:

String

if ok is false, containing the context and the current SDL error.

staticclear():Bool

Clears any error message currently set on the calling thread.

Returns:

true on success, false on failure.

staticget():String

Returns the last error message set on the calling thread.

Returns:

The error message, or an empty string if no error is set.

staticinlineinvalidParam(param:String):Bool

Sets the error message to a standard "invalid parameter" message naming param.

Parameters:

param

The name of the invalid parameter.

Returns:

Always false (for convenient return invalidParam(...) idioms).

staticoutOfMemory():Bool

Sets the error message to a standard "out of memory" message.

Returns:

true on success, false on failure.

staticset(message:String):Bool

Sets the error message for the calling thread. Always returns false, for convenient return set(...) idioms.

Parameters:

message

The error message to set.

Returns:

Always false.

staticinlineunsupported():Bool

Sets the error message to a standard "operation not supported" message.

Returns:

Always false (for convenient return unsupported() idioms).
