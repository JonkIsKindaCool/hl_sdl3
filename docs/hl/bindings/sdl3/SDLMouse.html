API Documentation

class SDLMouse

package hl.bindings.sdl3

@:access(String)

Static mouse input API.

Provides device enumeration, cursor position queries (window-relative, global, or relative-delta), pointer warping, relative mode, mouse capture, and creation of custom cursors.

Corresponds to the SDL3 mouse subsystem.

Static methods

staticcaptureMouse(enabled:Bool):Bool

Enables or disables mouse capture.

While captured, mouse events continue to be delivered even when the pointer leaves the window. This is useful for drag operations that should not be interrupted.

Parameters:

enabled

true to capture the mouse.

Returns:

true on success, false on failure.

staticcreateAnimatedCursor(frames:Array<{surface:SDLSurface, durationMs:Int}>, hotX:Int, hotY:Int):Null<SDLCursor>

Creates an animated cursor from a list of (surface, duration) frames.

A durationMs of 0 on a frame stops the animation on that frame. If the platform does not support animated cursors, SDL falls back to a static color cursor built from the first frame.

Parameters:

frames

An array of {surface, durationMs} entries, in order.

hotX

X coordinate of the click point within the cursor.

hotY

Y coordinate of the click point within the cursor.

Returns:

A new cursor, or null on failure.

staticcreateColorCursor(surface:SDLSurface, hotX:Int, hotY:Int):Null<SDLCursor>

Creates a color cursor from a surface.

Parameters:

surface

The surface containing the cursor image.

hotX

X coordinate of the click point within the cursor.

hotY

Y coordinate of the click point within the cursor.

Returns:

A new cursor, or null on failure.

staticcreateCursor(data:Bytes, mask:Bytes, w:Int, h:Int, hotX:Int, hotY:Int):Null<SDLCursor>

Creates a monochrome cursor from 1-bit-per-pixel bitmaps.

data is the AND mask (pixels that survive), mask is the XOR mask (pixels that get inverted). Both must be w * h / 8 bytes long.

Parameters:

data

The AND mask bitmap.

mask

The XOR mask bitmap.

w

Width in pixels; must be a multiple of 8.

h

Height in pixels.

hotX

X coordinate of the click point within the cursor.

hotY

Y coordinate of the click point within the cursor.

Returns:

A new cursor, or null on failure.

staticsetRelativeMouseMode(window:SDLWindow, enabled:Bool):Bool

Enables or disables relative mouse mode for a window.

In relative mode the mouse cursor is hidden and confined to the window, and only movement deltas are reported (via getRelativeState() and the xrel/yrel fields of MOUSE_MOTION events). This is the standard setup for first-person camera controls.

Parameters:

window

The window to configure.

enabled

true to enable relative mode.

Returns:

true on success, false on failure.

true on success, false on failure.

staticwarpInWindow(window:SDLWindow, x:Float, y:Float):Void

Parameters:

y

The new Y coordinate, relative to the window.
