API Documentation

class SDLKeycode

package hl.bindings.sdl3

Logical keycodes used by SDL keyboard events.

Unlike scancodes (which identify the physical key location), keycodes represent the symbol printed on the key according to the active keyboard layout. Use the constants in this class to compare against the key field of a SDLEvent.Key event.

Two special bit masks are used internally: - EXTENDED_MASK marks keycodes outside the ASCII range. - SCANCODE_MASK is used to encode scancodes in the same numeric space.

Corresponds to SDL_Keycode in SDL3.
