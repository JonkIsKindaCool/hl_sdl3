API Documentation

class SDLIOStream

package hl.bindings.sdl3

@:directlyUsed

A generic I/O stream abstraction for reading and writing bytes.

Streams can be backed by files, in-memory buffers, or custom sources. They support sequential and random access, and typed big-endian / little-endian read/write helpers.

Corresponds to SDL_IOStream in SDL3.
