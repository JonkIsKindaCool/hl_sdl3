API Documentation

class SDLCamera

package hl.bindings.sdl3

Represents an opened camera device. Corresponds to SDL_Camera in SDL3.

Static methods

staticgetCameras():Array<Int>

Returns a list of connected camera device IDs.

staticgetCurrentDriver():Null<String>

Returns the name of the currently initialized camera driver, or null.

staticgetDrivers():Array<String>

Returns a list of available camera driver names.

staticgetName(id:Int):Null<String>

Returns the human-readable name of a camera, or null.

staticgetPosition(id:Int):SDLCameraPosition

Returns the physical position of a camera.

staticgetSupportedFormats(id:Int):Array<SDLCameraSpec>

Returns a list of supported formats for a camera.

staticopen(id:Int, ?spec:SDLCameraSpec):Null<SDLCamera>

Opens a camera device.

Parameters:

id

The camera device ID.

spec

Optional desired format. May be null for defaults.

Returns:

A new camera instance, or null on failure.

Methods

acquireFrame():Null<SDLCameraFrame>

Acquires a frame from the camera. The frame must be released with SDLCameraFrame.release() when done.

Returns:

A frame, or null if no frame is available.

close():Void

Closes the camera and releases its resources.

getFormat():Null<SDLCameraSpec>

Returns the current format of the camera, or null on error.

getId():Int

Returns the device ID of this camera.

permission():SDLCameraPermission

Returns the current permission state of the camera.

readFrame():Null<SDLCameraImage>

Convenience method: acquires a frame, copies its pixels, and releases it.

Returns:

A SDLCameraImage with copied pixel data, or null on failure.
