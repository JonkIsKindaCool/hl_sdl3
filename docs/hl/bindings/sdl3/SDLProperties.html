API Documentation

class SDLProperties

package hl.bindings.sdl3

@:directlyUsed@:access(String)

A thread-safe set of typed name/value properties.

Property sets are the SDL 3 replacement for the older "hint" mechanism in contexts where more structure (typed values, reference counting, thread safety) is needed: texture descriptions, window creation, audio device configuration, and so on.

Each property has a name and a value of one of the types in SDLPropertyType. Values can be pointers, strings, integers, floats, or booleans. Iterating the set, copying it, and reading/writing individual properties are all supported.

There is a single process-wide property set accessible through getGlobal() — useful for application-wide configuration. Additional sets can be created with create() and destroyed with destroy().

Most SDL subsystems accept an integer property-set ID rather than the wrapper object; use rawId to retrieve it.

Corresponds to the SDL3 properties API (SDL_PropertiesID, SDL_SetStringProperty, SDL_GetNumberProperty, etc.).

Static methods

staticcreate():SDLProperties

Creates a new, empty property set.

The returned set should be released with destroy() when no longer needed.

Returns:

A wrapper around the newly created property set.

staticfromId(id:Int):SDLProperties

Wraps an existing property-set ID returned by another SDL subsystem.

Use this when SDL hands you a raw property-set ID (for example from a texture or window description) so you can read or write properties on it.

Parameters:

id

The raw property-set ID.

Returns:

A wrapper around the given ID.

staticgetGlobal():SDLProperties

Returns the process-wide global property set.

It is always available and never needs to be destroyed.

Returns:

A wrapper around the global property set.

Methods

clear(name:String):Bool

Removes a property from the set.

Parameters:

name

The property name to remove.

Returns:

true if the property existed and was removed, false otherwise.

copyTo(dst:SDLProperties):Bool

Copies every property from this set into dst.

Existing entries in dst with matching names are overwritten.

Parameters:

dst

The destination property set.

Returns:

true on success, false on failure.

destroy():Void

Destroys the property set and releases its resources.

Do not call this on the global property set returned by getGlobal(). After this call the instance must not be used again.
