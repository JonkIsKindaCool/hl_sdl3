class SDLHint

package hl.bindings.sdl3

Hints API.

Hints are string key/value pairs that let you influence SDL's behavior before or during initialization. Common uses include selecting a video or audio driver, disabling specific input devices, or tweaking rendering behavior.

Hints can also be set via environment variables of the same name. Setting a hint programmatically takes precedence over the environment variable.

Corresponds to the SDL3 hint API (SDL_SetHint, SDL_GetHint, SDL_AddHintCallback, and related functions).
