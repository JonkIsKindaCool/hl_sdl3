class SDLColorspace

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLPixels

Colorspace identifiers.

Describes how numeric color components should be interpreted (SDR sRGB, HDR10, various YUV coefficients, etc.). Used alongside a SDLPixelFormat to describe how a texture or surface should be sampled and displayed.

Corresponds to SDL_Colorspace in SDL3.
