API Documentation

class AsyncIO

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLAsyncIO

A handle for asynchronous I/O operations on a file. Corresponds to SDL_AsyncIO in SDL3.

Static methods

staticopen(path:String, mode:String, queue:SDLAsyncIOQueue):Null<AsyncIO>

Opens a file for asynchronous I/O. Corresponds to SDL_AsyncIOFromFile.

Parameters:

path

The file path.

mode

The open mode (similar to fopen). E.g. "r", "w", "r+".

queue

The queue to associate tasks with.

Returns:

A new instance, or null on failure.

Variables

read onlyqueue:SDLAsyncIOQueue

The queue associated with this object.

Methods

close(flush:Bool, ?cb:SDLAsyncIOCompletion ‑> Void):Bool

Closes the file asynchronously. Corresponds to SDL_CloseAsyncIO.

Parameters:

flush

If true, ensures data is flushed to disk.

cb

Optional callback invoked upon completion.

Returns:

true if the task was successfully enqueued. After this, the object is no longer valid.

getSize():Int64

Gets the size of the file. Corresponds to SDL_GetAsyncIOSize.

Returns:

The size in bytes, or a negative value on error.

read(offset:Int64, size:Int, cb:SDLAsyncIOCompletion ‑> Void):Bool

Starts an asynchronous read operation. Corresponds to SDL_ReadAsyncIO.

Parameters:

offset

The position to read from.

size

The maximum number of bytes to read.

cb

Callback invoked upon completion. The data is available in data.

Returns:

true if the task was successfully enqueued.

write(offset:Int64, data:Bytes, cb:SDLAsyncIOCompletion ‑> Void):Bool

Starts an asynchronous write operation. Corresponds to SDL_WriteAsyncIO.

Parameters:

offset

The position to write to.

data

The data to write. Must not be modified until the callback runs.

cb

Callback invoked upon completion.

Returns:

true if the task was successfully enqueued.
