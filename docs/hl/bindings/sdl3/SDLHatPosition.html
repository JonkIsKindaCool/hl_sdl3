package hl.bindings.sdl3

from Int to Int

import hl.bindings.sdl3.SDLJoystick

@:enum

The position of a joystick hat (D-pad) switch.

The values are a bitmask: UP/DOWN and LEFT/RIGHT can be combined, producing the diagonal positions (e.g. RIGHTUP).

Corresponds to SDL_HatPosition in SDL3.
