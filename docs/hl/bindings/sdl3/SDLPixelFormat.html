class SDLPixelFormat

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLPixels

Pixel format identifiers.

Each constant encodes a specific layout of color channels in memory: order of channels (RGB vs BGR, etc.), bit depth, whether there is an alpha channel, and its position. SDL uses these values throughout the surface, renderer, and texture APIs.

Corresponds to SDL_PixelFormat in SDL3.
