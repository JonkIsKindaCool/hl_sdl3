API Documentation

class SDLTexture

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLRender

@:directlyUsed

A GPU (or renderer-managed) image.

Created with SDLRenderer.createTexture or SDLRenderer.createTextureFromSurface. Call destroy() when done with it.

Corresponds to SDL_Texture in SDL3.

Variables

read onlyformat:Int

The pixel format of this texture.

Methods

destroy():Void

Destroys the texture and releases its resources.

Safe to call multiple times; the instance becomes unusable afterwards.

getAlphaMod():Int

Returns the current alpha multiplier for this texture.

Returns:

The alpha multiplier in [0, 255].

getBlendMode():Int

Returns the current blend mode for this texture.

Returns:

The active blend mode.

getColorMod():{r:Int, g:Int, b:Int}

Returns the current color multiplier for this texture.

Returns:

An object with r, g, b in [0, 255].

getPalette():Null<SDLPalette>

Returns the palette used by an indexed-color texture.

Returns:

The current palette, or null if the texture has none.

getScaleMode():SDLScaleMode

Returns the current scaling filter for this texture.

Returns:

The active scale mode.

getSize():{w:Float, h:Float}

Returns the size of the texture in pixels.

Returns:

An object with w and h fields.

lock(?rect:Null<SDLRect>):Null<{pixels:Bytes, pitch:Int}>

Locks a region of a STREAMING texture for direct pixel access.

The returned pixel pointer is only valid until unlock() is called. Write to it directly (e.g. with hl.Bytes.blit) and then call unlock().

Parameters:

rect

Region to lock, or null for the whole texture.

Returns:

An object with pixels and pitch, or null on failure.

update(?rect:Null<SDLRect>, pixels:Bytes, pitch:Int):Bool

Updates texture pixel data.

pixels must be packed according to the texture's format, with rows pitch bytes apart.

Parameters:

rect

Region to update, or null for the whole texture.

pixels

The source pixel data.

pitch

Number of bytes per row.

Returns:

true on success, false on failure.
