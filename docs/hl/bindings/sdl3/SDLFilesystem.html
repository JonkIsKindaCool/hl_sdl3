API Documentation

class SDLFilesystem

package hl.bindings.sdl3

Filesystem utilities for SDL3.

Provides cross-platform helpers for querying standard directories, manipulating paths, and enumerating directory contents.

Static methods

staticcopy(oldPath:String, newPath:String):Bool

Copies a file from oldPath to newPath.

Parameters:

oldPath

The source file path.

newPath

The destination file path.

Returns:

true on success, false on failure.

staticcreateDirectory(path:String):Bool

Creates a single directory. The parent directory must already exist.

Parameters:

path

The directory path to create.

Returns:

true on success, false on failure.

staticenumerate(path:String):Null<Array<String>>

Enumerates the contents of a directory.

Parameters:

path

The directory to enumerate.

Returns:

An array of entry names (not full paths), or null on failure.

staticexists(path:String):Bool

Checks whether a path exists.

Parameters:

path

The path to check.

Returns:

true if the path exists, false otherwise.

staticgetBasePath():Null<String>

Returns the base path of the application, i.e. the directory from which the executable was launched, or the bundle directory on macOS.

Returns:

The base path, or null on failure.

staticgetCurrentDirectory():Null<String>

Returns the current working directory of the process.

Returns:

The current directory, or null on failure.

staticgetPathInfo(path:String):Null<SDLPathInfo>

Returns detailed information about a filesystem path.

Parameters:

path

The path to query.

Returns:

A SDLPathInfo structure, or null if the path does not exist or an error occurred.

staticgetPrefPath(org:String, app:String):Null<String>

Returns the preferred path for storing user-specific application data.

This is typically a per-user, per-application directory that is safe to write to. The directory is created if it does not exist.

Parameters:

org

The name of your organization.

app

The name of your application.

Returns:

The preference path, or null on failure.

staticgetUserFolder(folder:SDLFolder):Null<String>

Returns the path to a standard user folder.

Parameters:

folder

The folder to query (e.g. SAVEDGAMES, DOCUMENTS).

Returns:

The folder path, or null if it could not be determined.

@:value({ caseInsensitive : false })staticglob(path:String, ?pattern:String, caseInsensitive:Bool = false):Null<Array<String>>

Enumerates files in a directory matching a glob pattern.

Parameters:

path

The directory to search.

pattern

Optional glob pattern (e.g. "*.png"). If omitted, all files are returned.

caseInsensitive

If true, matching is case-insensitive.

Returns:

An array of matching file names (not full paths), or null on failure.

staticisDirectory(path:String):Bool

Checks whether a path refers to a directory.

Parameters:

path

The path to check.

Returns:

true if the path exists and is a directory, false otherwise.

staticisFile(path:String):Bool

Checks whether a path refers to a regular file.

Parameters:

path

The path to check.

Returns:

true if the path exists and is a file, false otherwise.

staticjoin(base:String, name:String):String

Joins two path components with the platform-appropriate separator.

Parameters:

base

The base path.

name

The path component to append.

Returns:

The combined path.

staticremove(path:String):Bool

Removes a file or an empty directory.

Parameters:

path

The path to remove.

Returns:

true on success, false on failure.

staticrename(oldPath:String, newPath:String):Bool

Renames or moves a file or directory.

Parameters:

oldPath

The existing path.

newPath

The new path.

Returns:

true on success, false on failure.
