API Documentation

class SDLDateTime

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLTime

@:directlyUsed

A structure representing broken-down calendar date and time components.

Corresponds to SDL_DateTime in SDL3.

Constructor

@:value({ utcOffset : 0, dayOfWeek : 0, nanosecond : 0, second : 0, minute : 0, hour : 0, day : 0, month : 0, year : 0 })new(year:Int = 0, month:Int = 0, day:Int = 0, hour:Int = 0, minute:Int = 0, second:Int = 0, nanosecond:Int = 0, dayOfWeek:Int = 0, utcOffset:Int = 0)

Creates a new SDLDateTime instance with specified date and time components.

Variables

day:Int

Day of the month, from 1 to 31.

dayOfWeek:Int

Day of the week: 0 = Sunday, 1 = Monday, ..., 6 = Saturday.

hour:Int

Hour of the day, from 0 to 23.

minute:Int

Minute of the hour, from 0 to 59.

month:Int

Month of the year, from 1 (January) to 12 (December).

nanosecond:Int

Nanoseconds, from 0 to 999,999,999.

second:Int

Second of the minute, from 0 to 60 (allowing leap seconds).

utcOffset:Int

Offset from UTC in seconds.

year:Int

Year (e.g. 2026).

Methods

toString():String

Returns a string representation of the date and time in ISO-like format.

Returns:

A formatted string representation.
