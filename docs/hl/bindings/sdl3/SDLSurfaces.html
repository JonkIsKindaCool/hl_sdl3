API Documentation

class SDLSurfaces

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLSurface

@:access(String)

Static helpers for loading images from disk or streams, and for converting raw pixel buffers between formats.

Use these to obtain an SDLSurface from a file or memory buffer, or to convert a raw buffer directly when you don't need a full surface.

Corresponds to the SDL3 surface loading and pixel-conversion functions.

Static methods

staticconvertPixels(w:Int, h:Int, srcFormat:Int, src:Bytes, srcPitch:Int, dstFormat:Int, dst:Bytes, dstPitch:Int):Bool

Converts pixel data between two formats, directly between buffers.

No SDLSurface is involved; the operation is performed row by row.

Parameters:

w

Width in pixels.

h

Height in pixels.

srcFormat

Pixel format of the source buffer.

src

Source pixel data.

srcPitch

Bytes per row in the source buffer.

dstFormat

Pixel format of the destination buffer.

dst

Destination pixel data.

dstPitch

Bytes per row in the destination buffer.

Returns:

true on success, false on failure.

staticload(path:String):Null<SDLSurface>

Loads an image, auto-detecting its format from its content.

The set of supported formats depends on how SDL was built; typically BMP and PNG are always available, and others may be added by SDL_image.

Parameters:

path

Path to the image file.

Returns:

The loaded surface, or null on failure.

staticloadBMP(path:String):Null<SDLSurface>

Loads a BMP image file into a new surface.

Returns:

The loaded surface, or null on failure.
