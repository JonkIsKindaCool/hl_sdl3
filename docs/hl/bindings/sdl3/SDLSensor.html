class SDLSensor

package hl.bindings.sdl3

@:access(String)

An open sensor device.

Open with SDLSensor.open() or SDLSensor.fromId(), read values with getData(), and remember to close() when done.

Corresponds to SDL_Sensor in SDL3.

Static methods

staticfromId(id:Int):Null<SDLSensor>

Returns the already-open sensor handle for a device ID, if any.

Parameters:

id

The sensor instance ID.

Returns:

The sensor handle, or null if not open.

staticopen(id:Int):Null<SDLSensor>

Opens a sensor by its instance ID.

Parameters:

id

The sensor instance ID (see SDLSensors.getSensors()).

Returns:

A new sensor handle, or null on failure.

Methods

close():Void

Closes the sensor and releases its resources.

Safe to call multiple times; the instance becomes unusable afterwards.

@:value({ numValues : 3 })getData(numValues:Int = 3):Null<Array<Float>>

Returns the latest reading from this sensor.

For accelerometers and gyroscopes the returned array holds [x, y, z] values (accelerations are in m/s², angular velocities in rad/s). Call this after SDLSensors.update() or after processing the event queue to get fresh values.

Parameters:

numValues

The number of values to read (default 3).

Returns:

The sensor values, or null on failure.
