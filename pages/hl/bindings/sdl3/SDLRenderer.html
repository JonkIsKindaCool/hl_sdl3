API Documentation

class SDLRenderer

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLRender

@:directlyUsed@:access(String)

A 2D hardware-accelerated (or software) rendering context bound to a window.

Create a renderer with SDLRenderer.create (or one of its variants), draw with the various point/line/rect/texture/geometry methods, then call present() to display the finished frame.

Remember to destroy() the renderer when you are done with it.

Corresponds to SDL_Renderer in SDL3.
