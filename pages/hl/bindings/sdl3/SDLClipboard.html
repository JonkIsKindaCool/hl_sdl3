API Documentation

class SDLClipboard

package hl.bindings.sdl3

Provides access to the system clipboard, including simple text and advanced multi‑MIME‑type data. Corresponds to the SDL3 clipboard API.

Static methods

staticclearData():Bool

Clears all data from the clipboard.

Returns:

true on success, false on failure.

staticgetData(mime:String):Null<Bytes>

Retrieves clipboard data for a given MIME type.

Parameters:

mime

The MIME type to fetch.

Returns:

The raw data, or null if not available.

staticgetMimeTypes():Array<String>

Returns a list of MIME types currently available on the clipboard.

Returns:

An array of MIME type strings.

staticgetPrimarySelectionText():String

Returns the current primary selection text (X11 only).

Returns:

The primary selection text, or an empty string if none.

staticgetString(mime:String):Null<String>

Retrieves clipboard data for a given MIME type as a string.

Parameters:

mime

The MIME type to fetch.

Returns:

The string value, or null if not available.

staticgetText():String

Returns the current clipboard text.

Returns:

The clipboard text, or an empty string if none.

Parameters:

mime

The MIME type to check.

Returns:

Checks whether the primary selection contains text (X11 only).

staticsetData(items:Map<String, Bytes>):Bool

Sets the clipboard data for multiple MIME types. This is the advanced clipboard API. Use setText for simple text.

Parameters:

items

A map from MIME type (e.g. "text/plain") to raw data.

Returns:

true on success, false on failure.

true on success, false on failure.
