API Documentation

class SDLWindow

package hl.bindings.sdl3

@:directlyUsed@:access(String)

An OS-level application window, created with SDLWindow.create (or one of its variants).

Combine with SDLRenderer for hardware-accelerated drawing, or use getSurface for software rendering. Call destroy when done with the window.

Corresponds to SDL_Window in SDL3.
