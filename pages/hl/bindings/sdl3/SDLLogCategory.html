enum abstract SDLLogCategory(Int)

package hl.bindings.sdl3

from Int to Int

import hl.bindings.sdl3.SDLLog

@:enum

Categories used to group log messages by subsystem.

Each category has its own independent priority threshold, which can be set with SDLLog.setPriority. CUSTOM is the first value that can be used by applications for their own categories.

Corresponds to SDL_LogCategory in SDL3.
