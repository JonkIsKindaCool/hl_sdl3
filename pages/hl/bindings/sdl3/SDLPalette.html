API Documentation

class SDLPalette

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLPixels

@:directlyUsed

A palette of colors, used by palette-indexed pixel formats.

Corresponds to SDL_Palette in SDL3.

Constructor

new(ncolors:Int)

Creates a new palette with the given number of colors.

Parameters:

ncolors

The number of color entries the palette should hold.

Variables

read onlyncolors:Int

The number of color entries in the palette.

Methods

destroy():Void

Destroys the palette and releases its resources.

Safe to call multiple times; the instance becomes unusable afterwards. Do not destroy a palette while a surface still references it.

getColor(index:Int):Null<SDLColor>

Returns the color at the given palette index.

Parameters:

index

The palette index.

Returns:

The color at that index, or null on failure.

@:value({ firstColor : 0 })setColors(colors:Array<SDLColor>, firstColor:Int = 0):Bool

Replaces a range of colors in the palette.

Parameters:

colors

The new colors, applied starting at firstColor.

firstColor

The first palette index to overwrite (default 0).

Returns:

true on success, false on failure.
