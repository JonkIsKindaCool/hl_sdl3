API Documentation

class SDLCondition

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLMutex

A condition variable.

Used together with a SDLMutex to let threads wait for a condition to become true without busy-looping. The typical pattern is:

mutex.lock();
while (!condition) cond.wait(mutex);
// ... consume the condition ...
mutex.unlock();

Corresponds to SDL_Condition in SDL3.

Constructor

new()

Creates a new condition variable.

Methods

broadcast():Void

Wakes up every thread currently waiting on this condition variable.

destroy():Void

Destroys the condition variable and releases its resources.

Safe to call multiple times; the instance becomes unusable afterwards. No thread must be waiting on it at the time of destruction.

signal():Void

Wakes up one thread waiting on this condition variable.

If no thread is waiting, this is a no-op.

wait(mutex:SDLMutex):Void

Atomically releases mutex and waits until the condition is signaled.

The calling thread must hold mutex before calling this. When the function returns, mutex is re-acquired.

Parameters:

mutex

The mutex associated with the condition.

waitTimeout(mutex:SDLMutex, timeoutMs:Int):Bool

Like wait(), but gives up after timeoutMs milliseconds.

Parameters:

mutex

The mutex associated with the condition.

timeoutMs

Maximum wait time, in milliseconds.

Returns:

true if the condition was signaled, false on timeout.
