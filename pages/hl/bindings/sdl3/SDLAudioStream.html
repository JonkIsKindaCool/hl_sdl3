API Documentation

class SDLAudioStream

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLAudio

SDL_AudioStream: converts, remaps, and buffers PCM audio.

Static methods

staticcreate(?src:SDLAudioSpec, ?dst:SDLAudioSpec):Null<SDLAudioStream>

Creates a standalone stream (not bound to a device). The src and dst specs may be null and set later with setFormat/bind.

Returns:

A new stream, or null on failure.

@:value({ devid : SDLAudio.DEFAULT_PLAYBACK })staticopenDeviceStream(devid:Int = SDLAudio.DEFAULT_PLAYBACK, ?spec:SDLAudioSpec):Null<SDLAudioStream>

Opens a device, creates a stream, and binds them in one call. The device starts PAUSED: call resumeDevice() to start playback. Destroying the stream will also close the device.

Parameters:

devid

Device ID, defaults to DEFAULT_PLAYBACK.

spec

Optional audio specification.

Returns:

A new stream, or null on failure.

Variables

frequencyRatio:Float

Gets or sets the frequency ratio. 1.0 = normal; >1 faster and higher pitch; range 0.01 to 100.

gain:Float

Gets or sets the stream gain (volume).

Methods

available():Int

Returns the number of converted bytes available to read.

clear():Bool

Clears the stream, removing all queued audio.

destroy():Void

Destroys the stream. If created with openDeviceStream, the device is also closed.

flush():Bool

Flushes the stream, discarding any pending audio.

@:value({ len : -1, pos : 0 })get(out:Bytes, pos:Int = 0, len:Int = -1):Int

Reads converted audio into out.

Returns:

Number of bytes read, or -1 on error.

getDeviceId():Int

Returns the device ID this stream is bound to, or 0 if none.

getFormat():Null<{src:SDLAudioSpec, dst:SDLAudioSpec}>

Returns the current input and output formats, or null on error.

isDevicePaused():Bool

Returns true if the bound device is paused.

lock():Bool

Locks the stream for direct access.

pauseDevice():Bool

Pauses the bound device.

@:value({ len : -1, pos : 0 })put(data:Bytes, pos:Int = 0, len:Int = -1):Bool

Enqueues len bytes (default: all) from data starting at pos. SDL copies the data, so the buffer can be reused immediately.

Returns:

true on success.

queued():Int

Returns the number of bytes queued in the stream (input format).

resumeDevice():Bool

Resumes the bound device.

setFormat(?src:SDLAudioSpec, ?dst:SDLAudioSpec):Bool

Sets the input and/or output audio format.

Parameters:

src

Source format (may be null to leave unchanged).

dst

Destination format (may be null to leave unchanged).

Returns:

true on success.

setInputChannelMap(?map:Array<Int>):Bool

Sets the input channel map. null resets the map. Each element is a destination channel; -1 silences it.

setOutputChannelMap(?map:Array<Int>):Bool

Sets the output channel map. null resets the map. Each element is a destination channel; -1 silences it.

unbind():Void

Unbinds the stream from its device.

unlock():Bool

Unlocks the stream.
