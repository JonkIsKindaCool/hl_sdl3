API Documentation

class SDLTrayMenu

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLTray

@:directlyUsed

Represents a menu or submenu attached to a system tray icon or tray entry.

Corresponds to SDL_TrayMenu in SDL3.

Methods

inlineaddSeparator():Null<SDLTrayEntry>

Adds a horizontal separator line to the end of the menu.

Corresponds to SDL_InsertTrayEntryAt with a null label in SDL3.

Returns:

The newly created separator SDLTrayEntry, or null on failure.

@:value({ flags : BUTTON })inlineappend(?label:String, flags:SDLTrayEntryFlags = BUTTON):Null<SDLTrayEntry>

Appends a new entry to the end of the menu.

Corresponds to SDL_InsertTrayEntryAt in SDL3.

Parameters:

label

Text label for the entry.

flags

Entry type and status flags (default: BUTTON).

Returns:

The newly created SDLTrayEntry, or null on failure.

createSubmenu(entry:SDLTrayEntry):Null<SDLTrayMenu>

Creates a submenu attached to a specific tray entry.

Corresponds to SDL_CreateTraySubmenu in SDL3.

Parameters:

entry

The parent tray entry that will open this submenu.

Returns:

A new SDLTrayMenu instance, or null on failure.

getEntries():Array<SDLTrayEntry>

Gets an array containing all entries in this menu.

Corresponds to SDL_GetTrayEntries in SDL3.

Returns:

An array of SDLTrayEntry items.

getEntriesCount():Int

Gets the total number of entries in this menu.

Corresponds to SDL_GetTrayEntries in SDL3.

Returns:

The entry count.

getEntryAt(index:Int):Null<SDLTrayEntry>

Gets the tray entry at a specific zero-based index.

Corresponds to SDL_GetTrayEntries in SDL3.

Parameters:

index

Zero-based index of the entry.

Returns:

The SDLTrayEntry at the specified position, or null if out of bounds.

getParentEntry():Null<SDLTrayEntry>

Gets the parent tray entry containing this submenu.

Corresponds to SDL_GetTrayMenuParentEntry in SDL3.

Returns:

The parent SDLTrayEntry, or null if this is a top-level tray menu.

getParentTray():Null<SDLTray>

Gets the parent system tray icon containing this menu.

Corresponds to SDL_GetTrayMenuParentTray in SDL3.

Returns:

The parent SDLTray, or null if this is a submenu.

getSubmenu(entry:SDLTrayEntry):Null<SDLTrayMenu>

Gets the submenu associated with a specific tray entry.

Corresponds to SDL_GetTraySubmenu in SDL3.

Parameters:

entry

The tray entry.

Returns:

The SDLTrayMenu attached to the entry, or null if none exists.

@:value({ flags : BUTTON })insert(pos:Int, ?label:String, flags:SDLTrayEntryFlags = BUTTON):Null<SDLTrayEntry>

Inserts a new entry into the menu at the specified position.

Corresponds to SDL_InsertTrayEntryAt in SDL3.

Parameters:

pos

Zero-based position to insert the entry, or -1 to append at the end.

label

Text label for the entry, or null to create a separator.

flags

Entry type and status flags (default: BUTTON).

Returns:

The newly created SDLTrayEntry, or null on failure.
