API Documentation

class SDLScancode

package hl.bindings.sdl3

Physical key positions on a keyboard.

Unlike keycodes (which depend on the active keyboard layout), scancodes identify the physical location of a key and are stable across layouts. They match the USB HID usage table plus a few platform-specific extras.

Use these constants when you want a key binding to follow the physical position of a key (e.g. WASD movement stays on the same physical keys regardless of whether the user has a QWERTY, AZERTY, or Dvorak layout).

Corresponds to SDL_Scancode in SDL3.
