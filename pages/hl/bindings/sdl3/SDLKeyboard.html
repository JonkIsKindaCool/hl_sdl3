API Documentation

class SDLKeyboard

package hl.bindings.sdl3

Static keyboard input API.

Provides device enumeration, key state queries (both by scancode and keycode), scancode/keycode translation helpers, and the text input / IME control functions used with on-screen keyboards.

Corresponds to the SDL3 keyboard subsystem.

Converts a scancode (physical key) to a keycode (logical key).

The result depends on the current keyboard layout and on the modifiers supplied in modstate.

If true, treat scancode as coming from an event (this affects certain layout-dependent keys).

staticstartTextInput(window:SDLWindow):Bool

Starts accepting text input (and IME composition) for window.

After this call, SDL will deliver TEXT_INPUT and TEXT_EDITING events for the window. Stop it with stopTextInput().

Parameters:

window

The window that should receive text input.

Returns:

true on success, false on failure.

staticstartTextInputWithProperties(window:SDLWindow, ?options:Null<SDLTextInputOptions>):Bool

Like startTextInput(), but with extra hints for the platform's on-screen keyboard (input type, capitalization, autocorrect, etc.).

All options are optional; unspecified fields use sensible defaults (TEXT type, SENTENCES capitalization, autocorrect and multiline on).

The window that should receive text input.

Returns:

true on success, false on failure.
