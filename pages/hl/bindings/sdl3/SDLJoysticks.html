class SDLJoysticks

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLJoystick

Static joystick subsystem API.

Provides device enumeration, metadata queries (that do not require opening the joystick), virtual joystick creation, and global subsystem settings.

Corresponds to the SDL3 joystick subsystem functions that operate on device instance IDs rather than open handles.

@:value({ axisMask : 0, buttonMask : 0, nhats : 0, nballs : 0, nbuttons : 0, naxes : 0, productId : 0, vendorId : 0 })staticattachVirtual(type:SDLJoystickType, vendorId:Int = 0, productId:Int = 0, naxes:Int = 0, nbuttons:Int = 0, nballs:Int = 0, nhats:Int = 0, buttonMask:Int = 0, axisMask:Int = 0, ?name:String):Int

Creates a virtual (software-simulated) joystick.

Useful for testing or for feeding input from a custom source through SDL's joystick API. Detach it with detachVirtual() when done.

Parameters:

type

The type/category of the virtual joystick.

vendorId

The USB vendor ID to report.

productId

The USB product ID to report.

naxes

Number of axes the virtual joystick supports.

nbuttons

Number of buttons the virtual joystick supports.

nballs

Number of trackballs the virtual joystick supports.

nhats

Number of hats the virtual joystick supports.

buttonMask

A bitmask of SDL gamepad button bindings.

axisMask

A bitmask of SDL gamepad axis bindings.

name

Optional joystick name.

Returns:

The new joystick instance ID, or -1 on failure.

staticlock():Void
