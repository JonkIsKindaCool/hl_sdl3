API Documentation

class SDLHidDevice

package hl.bindings.sdl3

import hl.bindings.sdl3.SDLHid

An open handle to a raw HID device.

Provides read/write access and control-transfer helpers. Remember to close() the handle when done.

Static methods

staticopen(vendorId:Int, productId:Int, ?serialNumber:String):Null<SDLHidDevice>

Opens a HID device by vendor/product ID.

Parameters:

vendorId

The USB vendor ID.

productId

The USB product ID.

serialNumber

Optional serial number to disambiguate between multiple identical devices.

Returns:

A new device handle, or null on failure.

staticopenPath(path:String):Null<SDLHidDevice>

Opens a HID device by its platform-specific path.

The path is the value returned in SDLHidDeviceInfo.path.

Parameters:

path

The device path.

Returns:

A new device handle, or null on failure.

Methods

close():Void

Closes the device handle and releases its resources.

Safe to call multiple times; the handle becomes unusable afterwards.
