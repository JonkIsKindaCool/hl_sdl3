API Documentation

class SDLPixels

package hl.bindings.sdl3

@:access(String)

Static pixel format utilities.

Provides conversions between pixel formats, raw channel values, and pixel values encoded as integers. Most applications only need mapRGBA() and getRGBA() when manually manipulating pixel data; the surface and renderer APIs handle the rest.

Corresponds to the SDL3 pixel format API.

Static methods

staticgetFormatDetails(format:Int):Null<SDLPixelFormatDetails>

Returns detailed information about a pixel format.

Parameters:

format

The pixel format to query.

Returns:

The format details, or null on failure.

staticgetFormatForMasks(bpp:Int, rmask:Int, gmask:Int, bmask:Int, amask:Int):Int

Finds the pixel format that corresponds to the given channel masks.

Parameters:

bpp

Bits per pixel.

rmask

Red channel mask.

gmask

Green channel mask.

bmask

Blue channel mask.

amask

Alpha channel mask (0 if no alpha).

Returns:

The matching pixel format, or UNKNOWN if no match is found.

staticgetFormatName(format:Int):Null<String>

Returns the human-readable name of a pixel format.

Parameters:

format

The pixel format to describe.

Returns:

The name (e.g. "SDL_PIXELFORMAT_RGBA8888"), or null on failure.

staticgetMasksForFormat(format:Int):Null<SDLPixelMasks>

Returns the channel masks for a pixel format.

Parameters:

format

The pixel format to query.

Returns:

The channel masks, or null on failure.

staticgetRGB(pixelvalue:Int, format:Int, ?palette:SDLPalette):SDLColor

Extracts the RGB components from a pixel value.

The alpha component is not extracted; the returned SDLColor always has a = 255.

Parameters:

pixelvalue

The raw pixel value.

format

The pixel format the value is encoded in.

palette

Optional palette for palette-indexed formats.

Returns:

The decoded SDLColor.

staticgetRGBA(pixelvalue:Int, format:Int, ?palette:SDLPalette):SDLColor

Extracts the RGBA components from a pixel value.

Parameters:

pixelvalue

The raw pixel value.

format

The pixel format the value is encoded in.

palette

Optional palette for palette-indexed formats.

Returns:

The decoded SDLColor, including its alpha channel.

staticmapRGB(format:Int, r:Int, g:Int, b:Int, ?palette:SDLPalette):Int

Maps an RGB triple to a pixel value in the given format.

The alpha component is set to fully opaque. For palette-indexed formats a palette must be supplied.

Parameters:

format

The pixel format of the destination.

r

Red component in [0, 255].

g

Green component in [0, 255].

b

Blue component in [0, 255].

palette

Optional palette for palette-indexed formats.

Returns:

The packed pixel value.

staticmapRGBA(format:Int, r:Int, g:Int, b:Int, a:Int, ?palette:SDLPalette):Int

Maps an RGBA quadruple to a pixel value in the given format.

For palette-indexed formats a palette must be supplied.

Parameters:

format

The pixel format of the destination.

r

Red component in [0, 255].

g

Green component in [0, 255].

b

Blue component in [0, 255].

a

Alpha component in [0, 255].

palette

Optional palette for palette-indexed formats.

Returns:

The packed pixel value.
