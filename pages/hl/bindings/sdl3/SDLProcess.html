API Documentation

class SDLProcess

package hl.bindings.sdl3

External process management.

Creates and controls child processes, with support for redirecting their standard streams to SDLIOStreams so that input/output can be exchanged from Haxe. Useful for launching external tools (ffmpeg, git, a browser, etc.) and reading their output.

Each instance represents a single child process. Call destroy() once you are done with it, and be aware that destroy() will block until the child terminates if it is still running.

Corresponds to the SDL3 process API (SDL_CreateProcess, SDL_CreateProcessWithProperties, SDL_KillProcess, SDL_WaitProcess, and related functions).

Static methods

@:value({ pipeStdio : false })staticcreate(args:Array<String>, pipeStdio:Bool = false):Null<SDLProcess>

Creates a child process from an argument vector.

The first element of args is the program to run; the rest are its arguments. Path resolution follows platform conventions; on Unix-like systems, args[0] must be an absolute path or found in PATH.

Parameters:

args

The command line as an array of arguments.

pipeStdio

If true, the child's stdin/stdout/stderr are connected to streams retrievable via getInput(), getOutput(), and getStderr(). If false, they are inherited from the parent.

Returns:

A new SDLProcess, or null on failure.

staticcreateWithProperties(args:Array<String>, ?options:Null<SDLProcessCreateOptions>):Null<SDLProcess>

Creates a child process with fine-grained control over its environment.

Allows setting the working directory, redirecting each standard stream to a specific SDLIOStream, merging stderr into stdout, and running the child in the background.

Parameters:

args

The command line as an array of arguments.

options

Optional creation options; unspecified fields use platform defaults.

Returns:

A new SDLProcess, or null on failure.

Methods

destroy():Void

Destroys the process handle and releases its resources.

If the child is still running, this call blocks until it exits. The instance becomes unusable afterwards.

getInput():Null<SDLIOStream>

Returns the stream connected to the child's standard input.

Only available if the process was created with pipeStdio = true or an explicit APP/REDIRECT option for stdin.

Returns:

The input stream, or null if it is not exposed.

getOutput():Null<SDLIOStream>

Returns the stream connected to the child's standard output.

Only available if the process was created with pipeStdio = true or an explicit APP/REDIRECT option for stdout.

Returns:

The output stream, or null if it is not exposed.

getStderr():Null<SDLIOStream>

Returns the stream connected to the child's standard error.

Only available if the process was created with pipeStdio = true or an explicit APP/REDIRECT option for stderr.

Returns:

The error stream, or null if it is not exposed.

kill(force:Bool):Bool

Requests the child process to terminate.

Parameters:

force

If true, kill the process immediately. If false, ask it to exit gracefully (on Unix this sends SIGTERM).

Returns:

true if the request was sent, false on failure.

read():Null<SDLProcessReadResult>

Reads any available output from the child process and reports its exit code.

The returned SDLProcessReadResult contains whatever bytes are currently available from the child's stdout (or merged stdout+stderr) and the child's exit code if it has already exited (otherwise -1). Call this in a loop until it returns null.

Returns:

The next chunk of process output and the current exit code, or null if the process has been fully drained and exited.

waitProcess(block:Bool):Null<Int>

Waits for the child process to exit and returns its exit code.

Parameters:

block

If true, wait indefinitely for the process to exit. If false, return immediately if the process is still running.

Returns:

The process exit code, or null if block was false and the process has not exited yet (or on failure).
